# StoryShape Feedback

StoryShape is a writing and worldbuilding application for people building stories across books, characters, places, and ideas. Its workspaces bring planning, drafting, revision, and worldbuilding together in one place.

**Your story. Your world. Your own.**

[Visit StoryShape.app](https://storyshape.app) · [Download the latest Mac beta](https://github.com/IronCandleInteractive/StoryShape/releases/latest) · [Support & FAQ](https://storyshape.app/support/)

## Availability and pricing

- **macOS:** Free. The current Apple-silicon beta is available from the [latest public release](https://github.com/IronCandleInteractive/StoryShape/releases/latest).
- **Windows:** Free, planned; not available yet.
- **Linux:** Free, planned; not available yet.
- **iPadOS:** In development, planned at **$4.99 one time**. It is not available for purchase yet.

Desktop editions remain free, without subscriptions, advertisements, or paid feature unlocks. StoryShape does not require an account for ordinary writing. The application is independently developed and its future first-party source is proprietary. Earlier source versions published under Apache License 2.0 retain their original license grants.

## Development model update

StoryShape is moving to a privately maintained development model. The desktop application remains completely free, and our commitment to offline writing, user privacy, and ownership of your work is unchanged.

Future application source code will be maintained privately by Iron Candle Interactive. Previously published versions released under Apache 2.0 retain their original licensing rights.

We’re continuing to welcome bug reports, feature requests, and feedback from writers as StoryShape develops.

Writers retain ownership of their manuscripts, notes, characters, research, worldbuilding, and other original content. StoryShape is designed for offline work and does not add advertising or tracking.

## Share feedback

Use **Issues** in this repository to report a bug, request a feature, or share general feedback. Choose the matching form and include only information you are comfortable making public. Do not attach private manuscripts, full project files, personal information, passwords, or other sensitive material. A small synthetic example is usually enough.

For private security concerns, use the contact in [SECURITY.md](SECURITY.md). For other support, email [support@ironcandleinteractive.com](mailto:support@ironcandleinteractive.com).

This repository is for user communication and public documentation. It does not contain StoryShape application source code. Public code contributions and pull requests are not accepted.
