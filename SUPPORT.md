# Support

- Read the [StoryShape Support & FAQ](https://storyshape.app/support/).
- Report a bug or request a feature using the issue forms in this repository.
- Email [support@ironcandleinteractive.com](mailto:support@ironcandleinteractive.com) for account-free product support, accessibility feedback, or questions that should not be public.

For bug reports, include the app version, operating system, steps to reproduce, expected result, and actual result. Please remove private manuscript text and use a small synthetic example whenever possible.
