# Private security reports

Please do not report a suspected security issue in a public GitHub issue. Email [support@ironcandleinteractive.com](mailto:support@ironcandleinteractive.com?subject=Private%20security%20report) with the subject **Private security report**. Include a description and steps to reproduce, but do not attach a manuscript or private StoryShape project.

We will review the report and respond when we can. Please allow time for investigation before sharing details publicly.
